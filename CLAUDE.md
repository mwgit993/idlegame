# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Udderly Idle is a Godot 4.7 (GDScript) idle/clicker game: milk a cow, build dairy businesses, hire farmhands, prestige with golden cowbells. Gameplay is described in `README.md`. The code style follows Matthew's other game, Star Viper (`mwgit993/spacegame`): everything generated in code, strict static typing, a headless smoke test. The art is different: bright, goofy cartoon drawing made with Godot's vector API (polygons, circles, thick antialiased outlines), not pixel art. The only asset file is the font.

## Commands

`godot` means the Godot 4.7.x editor binary.

```bash
godot --headless --path . --import                         # once on a fresh clone
godot --headless --path . --quit-after 30 -- --smoke-test  # must print UDDERLY_SMOKE_TEST_PASSED with zero script errors
godot --path .                                             # play
```

On a fresh clone the first `--import` prints a few `ERROR`s about the project font (`fredoka.tres`) because it is loaded before the `.ttf` has been imported. They are harmless; the smoke test right after is clean.

The smoke test (`_run_smoke_test` in `scripts/main.gd`) drives the economy and every tab by calling methods directly, checks the results with `_check`, and exits 1 on any failure. It points `Farm.save_path` at `user://smoke_test_save.json`, so real saves are safe. If you add a business, upgrade kind or tab, extend it. `_smoke_check_nav` steps the controller selection with synthetic d-pad, stick, button and key events (`Input.parse_input_event`), so it exercises the real input path.

## Code conventions

- Explicit static types everywhere. Don't use `:=` when the right-hand side is a `Variant` (a Dictionary lookup or an untyped Array element); cast instead, e.g. `float(b["cost"])`.
- A ternary (`a if c else b`) or `.filter()` produces an untyped Array; assigning that to an `Array[int]` / `Array[Dictionary]` variable fails at runtime. Use an `if` or a loop.
- The whole UI is built in code in `main.gd` with literal coordinates on a 640x360 layout. `scenes/main.tscn` is just a `Node2D` with `main.gd`.
- Rendering is smooth: `canvas_items` stretch with `fractional` scaling (vectors and text draw at the real window resolution), linear texture filtering, antialiased fonts and 4x 2D MSAA (`rendering/anti_aliasing/quality/msaa_2d`). Don't add image files; draw with `draw_colored_polygon` / `draw_circle` / `draw_polyline` / `draw_arc` and `StyleBoxFlat`.
- **Leave the `antialiased` argument of `draw_line` / `draw_polyline` / `draw_arc` / `draw_circle` off (the default).** Godot's line antialiasing adds a soft edge about 1.25 layout px wide. That width is in layout units, so on a 4K screen (6x) every outline gets a 7-pixel blur. MSAA already smooths every edge at the real resolution. Text and `StyleBoxFlat` are sharp at any size.
- On a big screen `Farm.fit_window_to_screen()` grows the 1280x720 starting window to about 80% of the screen (16:9, centred) before fullscreen is applied. It never shrinks it, and does nothing headless.
- Text uses Fredoka (SIL OFL, `assets/fonts/Fredoka-Variable.ttf`, licence in `assets/fonts/OFL.txt`). The project font is `assets/fonts/fredoka.tres`, a `FontVariation` at SemiBold (wght 600); `Art.font_bold` is the Bold (700) variant for the money counter, titles, bar labels and floaters. Sizes: 9 for small print, 10-12 for body text and buttons, 20 for the money counter (it shrinks to fit). Change a size with `_set_font_size`, which skips no-op overrides (an override re-lays-out the text).
- `game_data.gd`, `num_fmt.gd`, `cow.gd`, `milk_pails.gd` and `farm_scene.gd` are loaded with `preload` constants (`Data`, `Fmt`, `Cow`, `Pails`, `FarmScene`), not `class_name`, so a fresh clone doesn't need an import step to resolve them.

## Architecture

Autoloads, in load order:

| Autoload | Role |
| --- | --- |
| `Farm` (`scripts/autoload/farm.gd`) | All game state and economy: money, businesses, farmhands, upgrades, MOO RUSH, golden cowbells, offline earnings, save/load (`user://udderly_save.json`, autosave every 10 s and on quit). |
| `Art` (`scripts/autoload/pixel_art.gd`) | The cartoon art kit: palette, vector shape helpers (`ellipse`, `superellipse`, `blob`, `round_poly`, `rrect`, `heart`, `fill`/`outline`, `inked_stroke`, `clip`...) and every icon. Call `Art.draw_icon(canvas_item, "name", center, size)` from a draw callback; unknown names warn and draw the coin. The file kept its pixel-art-era name so the autoload line didn't change. |
| `Sfx` (`scripts/autoload/sfx.gd`) | Synthesizes the sound effects into `AudioStreamWAV`s. `Sfx.play("name")`; unknown names are silently ignored. `squirt` (the milking squeeze) and `moo` have several takes in `_variants`, and `play()` picks one at random. The moo is a pitch-contoured pulse train through moving vowel formants (`BandPass`). |
| `Music` (`scripts/autoload/music.gd`) | Background tune. The 32-bar loop (whistle, tuba, accordion, banjo, woodblock, shaker, kick, cowbell) is rendered once on a background thread at startup, in about 1 s, into a looping `AudioStreamWAV`. After that it costs nothing per frame. Its volume follows `Farm.music_volume`, and 0 stops it. Headless runs skip the render. The melody and chords are the `MEL_A`/`MEL_B` and `PROG_A`/`PROG_B` constants. |

- **Balance data** is all in `scripts/game_data.gd`: `BUSINESSES` (cost, growth, revenue, cycle time, farmhand), `UPGRADES` (kinds `biz`, `all`, `click`, `click_share`), milestones, MOO RUSH and cowbell constants. Change numbers there, not in `farm.gd`.
- **Economy rules** (in `farm.gd`): the next unit of a business costs `cost * growth^owned`; one cycle pays `revenue * owned * profit_mult * rush_mult`; `cycle_time` halves at each speed milestone. Without a farmhand a cycle must be started by clicking the business and stops after paying; with one it loops forever and catches up multiple cycles per frame when cycles get very short. Offline earnings pay `idle_income_per_sec() * seconds away` (farmhand-run businesses only, no MOO RUSH).
- **Prestige:** `bells_for_total(total_earned) = floor(BELL_SCALE * sqrt(total / BELL_UNIT))`. `move_pasture()` grants the difference, then `reset_pasture()` (keeps bells and lifetime stats).
- **UI** (`main.gd`): the background is `FarmScene` (`scripts/farm_scene.gd`): sky, sun, clouds, hills, barn, fence and flowers, each a `Control` that draws once (Godot keeps the draw commands). Per frame it only moves/rotates a few of them (drifting clouds, turning sun rays, swaying flowers, the MOO RUSH rainbow's alpha). The cow is `scripts/cow.gd`, a `Control` that redraws every frame: little springs for squash and stretch, big shiny eyes that glance a couple of pixels toward the mouse, blinks, a happy ^ ^ squint and open smile on every squeeze, ears, tail, and the MOO RUSH dance (heart eyes, tongue, hearts, sparkles). Her milk is `scripts/milk_pails.gd`, a helper she owns (`cow.pails`) and draws right after herself, so the pails stand in front of her legs. Each squeeze squirts drops from two teat tips, each aimed so its arc ends inside the rim of the pail under the udder. None reaches the grass. After `PAIL_SQUEEZES` squeezes the pail is full: it slides to one of two waiting spots beside the cow and a fresh pail drops in. If both spots are taken, the full pail stays put and extra milk just splashes. The wagon is a small state machine (`AWAY`, `ARRIVING`, `LOADING`, `LEAVING`). It comes `COLLECT_WAIT` seconds after a pail starts waiting, or at once when both spots are full. It rolls out from behind the dairy panel (the panel is drawn over the cow, so positions past x 234 are hidden), the pails hop in with a coin clink, and it rolls off. All of this is for show: `Farm.squeeze()` pays on the click. `_smoke_check_pails` drives it with `cow._process` and checks that every drop is caught, a full pail waits, the wagon collects it, and fast clicking can't overfill anything. She is drawn as a cute plush-toy mascot: a big round head on a small round body, solid black eyes with highlights (no white sclera, no pupils roaming inside it), rosy cheeks, a pink muzzle with small soft nostrils and a smile, rounded horn nubs and a fluffy tuft. The first cartoon version (googly eyes on top of the head, a huge snout with dark nostrils, a spiky tuft, a shocked O mouth on every squeeze) read as creepy, so keep new expressions friendly. `icon.svg` is her face built from the same shapes and numbers, and the MOON COW RANCH icon (`Art._icon_moon`) has a tiny side-view version of her; change them together. `main.gd` calls `cow.squeeze()` from `_on_squeeze`, which a flat Button over the cow triggers. The right panel has four pages (`Tab.DAIRY`, `UPGRADES`, `FARMHANDS`, `PASTURE`), each a `Control` toggled by `_set_tab`. `_process` calls `Farm.tick(delta)` and then `_refresh_all()`, which only refreshes the visible page. Progress bars, the MOO RUSH meter, icons, tab badges and the floating "+$" texts are drawn with `draw.connect(...)` callbacks.
- **Controller and keyboard** (the SELECTION section of `main.gd`): the d-pad, left stick or arrow keys move a selection ring (`nav_target`, drawn by `_draw_nav` on `nav_hl`, above everything) between buttons; `A` / `Enter` press it, `X` / `Space` milk from anywhere, `B` / `Esc` close the open popup or jump back to the cow, `START` opens or closes settings, `Y` / `B` cycle the buy amount, `LB` / `RB` switch tabs. Every visible `Button` is a target automatically (`_nav_targets`), and `_nav_activate_button` presses one by emitting `button_down`, `pressed` and `button_up`, so a new button needs no extra code. `_nav_step` picks the nearest button in the pushed direction, preferring ones lined up with the current one; the cow is the whole left column (up goes to the active tab, right returns to where you came from). While the popup is open only its buttons are targets. Directions are polled in `_nav_update` (stick deadzone `NAV_DEADZONE` with hysteresis `NAV_RELEASE`, one step per push, repeat after `NAV_REPEAT_DELAY`); button presses come through `_unhandled_input`. Moving the mouse past `NAV_MOUSE_SLOP` or clicking hides the ring; the next controller or arrow press shows it again (the first direction press only shows it, `A` shows it and presses). Buttons keep `FOCUS_NONE`: Godot's own focus and the `ui_*` actions aren't used (in 4.7 they include the d-pad and stick but not joypad `A`/`B`, and don't repeat the stick). Nothing scrolls today; if a page ever gets a `ScrollContainer`, make `_nav_select` scroll the target into view. `_smoke_check_nav` drives all of this with synthetic events.
- **Buttons** are styled by `_style_btn(b, kind)` (`cream`, `green`, `gold`, `red`, `pink`, `card`, `hired`; bright kinds get white outlined text) and squash/boing with tweens via `_bouncy`. Use `_set_kind` / `_set_enabled` in refresh code: they only touch the theme when something changes.
- **Settings:** the gear button at the right end of the top bar (`settings_btn`, `START` on a controller) opens a popup built by `_build_settings_popup`, modal like the welcome-back one (`_open_card()` says which popup owns the selection and input). DISPLAY flips `Farm.fullscreen` (`Farm.apply_display()`, also `F11`), MUSIC and SOUND step `Farm.music_volume` / `Farm.sfx_volume` by 0.1 between 0 and 1, NUMBERS cycles `Fmt.style` (`WORDS` "$3.200 BILLION", `SHORT` "$3.20B", `SCIENTIFIC` "$3.200e9"; only numbers from a million up change), SAVE NOW saves, and DELETE opens a second modal popup ("ARE YOU SURE?", `_build_delete_confirm`, KEEP MY FARM selected first) whose YES, DELETE calls `Farm.reset_save()` (settings survive). Each change saves at once; `Farm` saves and loads `fullscreen` and `number_style`. Whatever plays music should read `Farm.music_volume`. GDScript's `%` has no `%e`, so e-notation goes through `Fmt.sci`.
- Money is a `float` (64-bit), so it goes far past what an `int` can hold; `num_fmt.gd` names big numbers up to duodecillion.

## Adding content

- **Business:** add an entry to `Data.BUSINESSES` (with a farmhand), an icon for its id in `Art` (an `_icon_<name>` function drawn in a 32x32 box centred on 0,0, the id in `Art.ICONS` and a branch in `Art.draw_icon`; the smoke test checks every business has one), and check the dairy and farmhands pages still fit (8 rows of 36.5 px fill the panel; a 9th needs scrolling).
- **Upgrade:** add to `Data.UPGRADES`. The upgrades page lists the 7 cheapest not yet bought.
